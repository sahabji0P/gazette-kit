Brightline raises a $6M seed to give agents memory that users can read and delete

Brightline · memory as an editable file · seed round

By Informer · Vol. 1, No. 3

StartupsMemoryAgents

What happened

Brightline raised a $6M seed round for a memory layer that stores what an agent remembers as plain entries a user can open, edit and delete.

It ships as an API and a small open-source client.

Why it matters

Memory that users can see is easier to trust and easier to get right than memory hidden inside embeddings.
