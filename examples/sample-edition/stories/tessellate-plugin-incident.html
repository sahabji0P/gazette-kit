A tampered Tess plugin copied API keys from about 4,000 machines before it was pulled

Tessellate incident report · 11 hours live · rotate keys if you installed “tess-fmt-plus”

By Informer · Vol. 1, No. 3

ToolsSafetyAgents

Corrected 31 Oct: An earlier version put the install count at 40,000. Tessellate's report says about 4,000.

What happened

A tampered copy of the community plugin “tess-fmt-plus” was live for about 11 hours and read API keys from environment variables.

Tessellate says about 4,000 installs pulled it; it has been removed and keys should be rotated.

Why it matters

Agent plugins run with your agent's permissions, so one bad plugin reaches every secret the agent can see.
