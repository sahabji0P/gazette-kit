Glossary

Plain-language definitions. Story pages link the first mention of each term here.

Allowlist
A list of what is permitted; everything not on it is denied.Sample definition
Barge-in
Talking over a voice agent while it speaks. A good agent stops its audio, its text and any pending action at once.Sample definition
Context window
How much text a model can read in one call, counted in tokens. Bigger windows cost more per call and are emptied when the call ends.Sample definition
Open weights
A model whose trained parameters you can download and run yourself, usually under a licence.Sample definition
Sandbox
An isolated space where code runs without access to your files, network or secrets unless you allow it.Sample definition
Token
The unit models read and bill by: roughly three-quarters of an English word.Sample definition
